# Figures (v1.0 preprint)

These four figures belong to the **v1.0 retrospective manuscript** (`docs/lassa/paper-draft.md`; preprint on Zenodo) and are generated by `scripts/lassa/generate-figures-real.py` from the **2024 development model** (trained on weeks up to 2023, tested on 2024).

- `figure3_feature_importance.png` is that development model's gain importance. It is **not** the frozen v1.1 prospective model, which is refit on all labelled weeks; v1.1's importance is in [`../../../data/lassa/national-feature-importance.json`](../../../data/lassa/national-feature-importance.json), reproducible as described in [`VERIFY.md`](../../../VERIFY.md).
